# 审查发现处置

2026-10-08 用户授权精简当前流程。保留旧事故、原报告/等级/失败和有限次数历史；它们不自动成为本版待办或每批证明要求。

- 按当前版本真实后果判断：功能不可用、误执行、数据损坏、停止失效、未知假成功现在处理；用户允许的普通小范围 BUG 可后修；无本版关联的历史保持原级记录。
- 原报告不得改级或伪闭合。当前影响分类可以据证据更新，写明依据、现象和规避方法；延期和范围外保留不是 closed/pass。
- 并发、异常、身份或代际关键词不自动把一项发现变成全局重要阻断；有具体支持路径的现实正确性风险仍需处理。
- 修复和证据须作用于原问题实际发生的层次；只证明外层效果就如实保留原层未知。没有尝试依据的全称结论改为未验证。
- 验证针对当前根因和交付决定；不默认每个关键断言做反向突变、不穷举所有交错。需要独立复查的关联部分集中处理，不反复从头审整包。
- 当前已发请求、有限授权、模型和强度如实记录，失败/超时按原规则计数。不得因换 Goal/标题重置，也不自动加轮；达到授权上限只限制新增审查，其他安全工作继续。
- 原发现/未知按相关 ID 引用即可，不每次重述完整历史。新报告保留真正影响当前判断的未知和范围局限，不能无声丢失当前阻断。

详细执行范围以当前项目 AGENTS、交付流程及简化审查流程为准；旧的有重要项就反复会诊、所有重要项零 open、固定证明字段和默认单向收紧工序已从活跃正文移除。
