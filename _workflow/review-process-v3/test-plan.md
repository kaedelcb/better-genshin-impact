# 故障测试清单（施工前冻结）

|边界|反例|必须结果|
|方案|缺完整调用链/状态/故障方案|实施许可失败|
|前审|只有一份自写 pass / CLI 未产生有效报告|实施许可失败|
|独立读取|service 导航未列 storage，实际依赖存在|审查者可搜索、读取并指出漏洞|
|版本|源码新增、删除、修改，方案或配置变化|旧许可/报告按阶段失效|
|历史|接入时遗漏未决重要项、降低等级|审查/收口失败|
|预算|旧6次+新2次，第9次请求|禁止发出，修复/测试仍可做|
|锁|两个进程同时请求同一批|只允许一个请求，另一个不耗额|
|崩溃|保留发送前 reservation，无结果|占额且不可当通过，不自动解锁|
|路径|..、绝对路径、链接、User/bin/obj/auth|拒绝进入快照或读取|
|范围|报告只覆盖修改行、不覆盖调用链/故障/兼容|不能 pass|
|证据|通过报告被替换、输出为空/截断|不授予收口|
|继承|新 worktree 缺文件或版本不同|核验失败，不能声称已导入|
|兼容|历史已开工 v2|原验证仍可用；新批不可裸 v2 开工|
|质量|新的综合审查已通过，原回归未通过|原门禁仍阻断|

关键断言反向突变：去掉重要项阻断、快照漂移核对、预算上限、方案门、收口综合门；每个坏实现都必须使对应测试变红。
