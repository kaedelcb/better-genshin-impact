# 历史发送路由合同候选

仍沿原共享包、opening、原级发现与预算；不新开前审，不关闭停止资格合同冲突。当前只读辅助 Agent 无净收益：共享存储协议仍在集中修复，固定源码后的余一次 Sol/high 综合后审保持独立。

真实原 Host/端口发送、原正常收敛、原 Host 关闭、合法重开取得资格后，移除节点及凭据但保留流程操作。r4 在原关系判定断言实际红：当前关闭开关使原关系谓词返回 true。整个对账被其他封印挡住，r3 绿不能冒称假成功红。r1 编译失败、r2 恢复过期原租约的夹具失败均保留。

共享修复在每个发送意图同次耐久记录路由：true 为原节点仲裁；false 为原直通；缺字段是未知历史，不使用当前 Host 开关推断。Runner 消费实际边界合同，在发送前的 RecordIntent 内部路径记录，普通创建/Update/Mutate 不得补造或更改。历史和封印完整包含字段，缺字段省略保持旧格式。

|状态或故障|合法转换与判据|
|---|---|
|原节点已发、重开开关关闭、节点登记丢失|原关系谓词 false；终局 Unavailable；恢复原字节可 Effective，不重发|
|全部新锚缺失、节点登记缺失、原模式不可证|未知保持，不用当前开关或仅存流程登记证明无节点；不补造历史|
|原直通已发、重开开关打开|同次意图的 false 证明原直通；不新增节点责任|
|普通写者尝试新增/改路由字段|真实 RunStore 发布拒绝；原字节保持|
|旧格式且原节点登记完整|现有节点关系足以逐项核；可依法完成，不要求补字段|
|停止资格未知或坏租约|原 owner fence 零发布；原断言与新 oracle 继续保留，等待统一独立裁决|

写集为 WorkflowRunModels、WorkflowRunner、ArbitrationWorkflowExecutionBoundary、RunStore、RunStoreEvidenceGuard、TaskCenterHost.Admission 及具名测试。反例后集中实现；串行 Rebuild、定向/规定回归、关键 P/F/P 原子恢复、声明面和完整来源认证仍必须。普通证据不作认证、审查 pass 或实机交付。旧直通且所有可信路由证据丢失无法凭空重建，恢复来源及实际产品兼容义务仍 open，不能用保守阻断削功能后关闭责任。
