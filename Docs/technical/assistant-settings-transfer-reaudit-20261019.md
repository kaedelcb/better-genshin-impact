## 恢复与数据边界

写入前保存原字节、预写记录及同卷暂存文件的物理身份。导入失败恢复本事务确实发布的内容，保留其他写者文件。中断恢复时，缺原件、坏备份、旧记录无物理身份且目标归属不明，均保留恢复责任并明确失败，不猜测删除。

失败后的服务和界面重新读取当前落盘配置；不能恢复有效规则时继续暂停写入与新任务，停止入口保持可用。连接身份发生变化时保留旧停止绑定，暂停新写入，避免旧内存再次覆盖落盘的新配置。

正常修改助手配置会替换包内对应设置，导入前原件保存在唯一的 `backup-import-*` 目录；这与不覆盖已有计划和冲突资源的合并策略不同。迁移不保证任意不遵守写许可的旧程序或外部编辑器的原子并发协议；发现版本或物理身份不匹配时保留文件并失败。

开发验证均为明确隔离数据根、隔离管道、不可执行 BGI 占位文件和模拟自启登记。未向真实 User 导入、未部署或重启用户程序、未注入或改写第三方脚本。
