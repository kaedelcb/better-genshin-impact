# 助手设置与槲寄生配置迁移

设置页“导出全部设置”生成版本 2 的私有 ZIP；原有版本 1 设置包仍可导入。包内清单逐项记录长度和 SHA256，校验和目标规划全部成功后才写入。

## 范围

- 助手主配置、启动流程及全部方案、任务中心全部计划及当前选择、嘟嘟可、当前有效监控规则、桌宠和成员缓存。
- 本机 BGI 的 OneDragon、ScriptGroup、JsScript、AutoPathing、KeyMouseScript、AutoFight、AutoGeniusInvokation 业务资源目录；不修改第三方脚本源码。
- 协助房间迁移服务器、房间号和使用时间。原机 DPAPI 密码不出包，目标机已有密码保留，新增书签首次连接需重新输入密码。
- 不迁移运行记录、等待队列、租约、锁、实例身份、历史迁移事务资格；BGI 全局设置、角色队伍命名、软件本体和外部程序路径沿用目标机环境。

包中含用户私有账号及助手房间配置，应按私有备份保存。它与任务中心公开分享格式不同，不删除计划中的私有账号值。

## 恢复与冲突

任务中心已有计划保留。同身份同定义复用；同身份不同定义导入为新身份，并同步修复当前选择、启动流程及所有方案的嵌套引用。方案库合并，同名不同定义另存副本。本机原方案保留。

配置组和一条龙同名冲突另存副本，并修复配置名、组内委派、资源修订及已知助手引用。第三方脚本、路线或其他资源同路径不同内容时，整包在写入前拒绝；不会覆盖本机资源或向脚本注入代码。

主配置中的本机实例身份保留，有效本机 BGI 路径优先。跨机停止权威不移植，自动执行配置保留但需重新确认自动执行授权；导入本身不启动任务。

## 数据保护

仅在无活动任务、未知执行责任、挂载触发器及待发送命令时导入。迁移期间暂停设置写入与新任务，停止入口保持可用。

每批写入前生成唯一的 `backup-import-*` 目录及耐久事务记录。单个文件原子替换并读回；后续写入或运行时重载失败时，恢复原字节并删除本事务创建的新文件。迁移规划后目标若被其他写者修改或占用，拒绝覆盖；回滚也不覆盖其他写者的新版本。

若 UID、角色、服务器或 BGI 运行绑定改变，文件迁移仍成功，但暂停新任务和配置写入，保留旧连接的停止能力，界面明确说明新绑定在正常重新打开助手后生效。纯显示配置、流程节点、嘟嘟可及桌宠修改可继续使用。

配置重载覆盖所有相关服务、界面和待保存草稿。有效共享规则与本地规则参加同一事务；旧包缺项保持本机现状。

进程中断后，下次启动先完成未提交迁移恢复，再加载用户配置。备份损坏或外部写入导致恢复无法确认时保留原件、备份和恢复记录，暂停配置编辑及新任务并明确提示；不使用默认配置掩盖恢复失败。

开发验证只使用显式隔离数据根、隔离管道和假自启登记；不得向真实 User 导入样本。真实生产数据没有参与本次开发验证。
