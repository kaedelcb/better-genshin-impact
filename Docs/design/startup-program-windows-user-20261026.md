# 启动第三方程序：指定 Windows 用户

本次待办：补齐启动中心按用户名自动在另一 Windows 用户桌面启动第三方程序的能力，完成 UI、配置保存和执行接线；不要求用户手动建立计划任务。

验证目的：旧节点只会从当前用户启动，不能证明跨用户身份正确。以配置往返、会话选择、节点成功/失败/取消和隔离的真实跨用户启动验证决定是否交付；确认目标进程账号与会话、参数、工作目录、目标用户环境及一次性任务清理后结束。

使用方式：程序路径和启动参数照常填写，在新增的“Windows 用户名”填登录账号名，例如 `YS`、`.\YS` 或 `计算机名\YS`；留空维持原行为。用户名会显示在节点摘要中，保存方案和分支中的节点都会保留该字段。

边界：目标账号必须已登录且只有一个可确定的交互会话，跨用户需要管理员权限。无密码保存、自动登录或桌面切换。账号/会话/权限异常不会回退当前用户；未收到实际创建回执不会报告成功。这里只确认启动进程，不代表第三方软件内部登录或窗口已就绪。

实现：启动时自动登记无触发器的一次性 Windows 任务，以目标 SID 和 SessionId 执行助手短入口；此入口在单例和配置初始化之前分流，使用目标用户环境启动指定程序。父进程核验管道客户端的实际 SID 与会话，并等待启动结果；最后清理本次任务，不改任何已有任务和助手登录设置。
