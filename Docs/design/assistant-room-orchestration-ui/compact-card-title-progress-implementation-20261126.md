# 卡片标题合并进度及完成动作

用户确认 [设计图](compact-card-title-progress-design-20261126.png)。在已提交的桌面紧凑布局之上，仅调整编排卡片的第一行，不更改共享网页投影、执行状态、配置及房间切换业务。

- 标题包含房间身份/分类、紧凑进度卡、完成动作卡、更新时间和状态。原位于任务列表底部的整行进度和完成动作删除，未保留占位。宽度足够时显示更新时间；窄窗时间保留于可点击的完成动作详情。更窄的工作区仅在标题区域自然分两行，不重新把进度放入底部。
- 已确认进度使用小进度条和 `已完成数/总数`。没有任务记录显示绑定数量，未绑定单独标明；进度未确认或任务中存在未知时显示「进度待核对」，不绘制假进度条。不修改任何执行结果及排序。
- 完成动作摘要使用浅金色，长内容允许单行省略，点击复用原只读详情窗口，完整房间身份、分类、进度、完成动作、切房后动作、时间及既有作业/收尾原文均保留。实际编辑仍使用「编辑配置」。
- 复验 1180×860 和 980×720 实际 WPF 窗口、前序卡片和顶部布局、任务状态及详情可达性。
