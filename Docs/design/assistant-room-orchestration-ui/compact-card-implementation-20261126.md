# 编排房间卡片紧凑布局（2026-11-26）

用户确认 [第三版设计](compact-card-design-v3-20261126.png)：右栏采用两个并排的图标参数小卡、原编辑按钮、单行收尾提示/详情入口。早先的 [第一版](compact-card-design-20261126.png) 和 [第二版](compact-card-design-v2-20261126.png) 为历史设计迭代，不作为当前验收样式。

- 仅改 WPF 展示层，原执行状态、完成动作、房间配置、监控端认证/保存、网页 JSON 投影和数据保存协议均不变。
- 确切的「本机作业 … 已确认成功」在已完成任务行中折叠；空间足够时显示短作业号，窄窗或长任务名优先隐藏短号，不使任务名称挤压换行。非该类成功说明仍按原逻辑显示，不能丢弃异常原因。
- 房间整体说明迁入右栏一行，已知收尾信息显示短原因；完整原文及作业号在只读详情窗口中保留，可选择复制。鼠标点击和键盘激活均可打开，不要求仅悬停。该窗口展示打开时的快照，不执行操作。无房间/任务详情时整行折叠。
- 原状态颜色及标签仍由真实状态决定，断线未知不能显示为成功。定时待确认的时间值及待确认提示保留；更窄工作区继续将参数区自然移到任务下方。
- 定向验证需要检查普通及最小 WPF 窗口、任务短号、无详情时折叠、原始详情可访问以及原回归窗口；不以设计图冒充正式运行截图。
