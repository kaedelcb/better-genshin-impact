# 编排顶部状态条与分类标签紧凑化

用户确认 [单行三分区设计](compact-login-strip-design-20261126.png)，包括原先独占一行的「独立房间」。在此前 [卡片紧凑布局](compact-card-implementation-20261126.md) 基础上继续优化，不更改业务与网页协议。

- 登录、执行端、当前状态/提示三个分区横向排列，原房间名称和房号独立显示；最后确认房间必须仍标为「最后确认」，登录未知不得显示为已登录。
- 单执行实例显示名称；多个候选继续用原实际实例选择，名称冲突才附短标识，完整实例/机器身份保留在详情。不能据缩写决定操作目标。
- 「联机锄地已取消，正在确认清理」仅缩写成「清理确认中」，原「已取消」标签不变，不能将停止或清理中误解为清理完成。其他上下文保持原始语义，过长时单行省略，详情可复制完整原文。
- 「独立房间」及「另一条接力路线」移入各段首卡片的标题区，作为自然换行的分类标签，不再额外占一行。原分组和接力关系不改变。
- 复用只读详情窗口与现有下拉控件；正常及最小窗口保持单行，极窄工作区仅必要时自然换行。页面记忆保存失败的警告仍有单独可见位置，不隐藏。
