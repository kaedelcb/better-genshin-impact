## 确定的执行语义

| 所选起点 | 本次执行 |
| --- | --- |
| 主表中间任务 A | 从 A 开始；此前任务及流程不补跑；到后续车道时照常判断 |
| 独立车道本身 | 执行车道自己的内置选择步骤，只进入一条路线，再回主表 |
| 旧“流程+车道”配对的车道 | 归一化到原选择流程，完成条件后进入所选路线 |
| 车道内任务 B2 | 用户已明确选定该路线；从 B2 沿该路线余下任务执行，再汇合；不重评前面的判断，不进入另一支 |
| 启动单任务 B2 | 只执行 B2，不执行分支余下任务或公共后续 |
| 中途开始后再正常启动一次 | 新运行仍从默认入口开始；一次性标记受理后消费 |

不自动重新安装被跳过的监听流程，也不重放其中的寄存器写入、程序启动或等待。要让准备流程生效，应选择该流程作为入口。不存在、空白或重复身份仍明确拒绝，不回落链首。
