## 协议与修正

助手的普通执行回执使用 `control.remoteCommand` 中的 `cmd=ack`。重置、启动 BGI、绑定、定时和清除上线均从这里关联原 commandId 与 senderUid；网关送达 ack 不等于执行成功。此前网页重置只消费 `control.remoteCommandResult` 的缺口一并修正。任务配置应用继续要求 configRevision 与执行端纪元；策略读取/保存使用 `task_policy.data` / `task_policy.push_result`，读取失败不填默认值覆盖。

每个网页会话使用独立 web UID，避免同昵称页面接收彼此命令回执。状态广播不重建正在编辑的表单。任务启用状态以最后勾选值为准；一条龙保留 taskId 类型，配置组保持位置索引。
