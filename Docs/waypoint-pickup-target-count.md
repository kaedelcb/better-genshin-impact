# 线路节点按拾取数量结束动作

在执行线路所用的配置组中打开「拾够后提前结束节点动作」（默认关闭）。在需要计数的节点中填写同一个字段即可，不要求节点类型或动作类型，也不要求策略中的指令属于白名单：

- `"pickup_target_count": 2`：拾够 2 件，结束当前动作，下一点照常走。
- `"pickup_target_count": "2/3"`：拾够 2 件，结束当前动作并跳过紧接的 3 个点位。斜线写法必须加双引号。

只有数字的字符串（如 `"3"`）也可以，效果与数字 `3` 一样，不跳点。

仅统计当前节点左侧「获得」列表的新增行，每行算一次。标题和每个物品行都在原始截图上使用两次取色之间的窄范围（R 236–242、G 229–235、B 216–222），去掉单像素后至少有 5 个四连通块才判有文字。标题用于确认列表，标题本身不计数。不读物品名、图标、行尾数量或拾取日志。移动中以角色的新定位计算距离，先在移动前预备视觉基线，距离目标不超过 5 个线路距离单位开始计数；正常到点时也会直接接管，不追加移动或等待：还在执行上一点时也可以预备和提前开始，同一份计数带到目标点。当前点本身也是拾取点时，优先观察当前点。观察开始时已有的行不计，旧行停留或滚动不重复计。列表确认消失后，本点累计保留，之后再出现的行继续累加。到点时不会停下来等列表画面稳定；观察已开启时会在动作期间继续计数。暂停、失焦或画面不可信时不猜测拾取数，路线按原规则处理。

达标前照常执行原动作。达标时立即结束当前节点剩下的动作（包括策略指令和可取消的等待），先释放该节点尚未松开的键，再继续执行路线。原拾取点动作结束前达标时，使用斜线写法会直接跳过指定补捡点的移动和动作；普通走路点也计入要跳过的点位数。没有拾够时，后续点位照常执行。已经发给游戏的操作无法撤回；松开长按的技能键也可能释放技能。

使用斜线写法且当前动作结束仍未达标时，会在走向首个补捡点的途中继续计数，不额外停等。新定位仍在原拾取点 5 个距离单位内才计入；越界、定位失效或补捡动作即将开始时结束这段观察。若途中达标，走完当前移动并松开移动键，再略过该补捡点的动作和其余可跳点；离点后的跳转不会跳过另一个独立拾取点或跨地图。

只跳过用于补捡的点位，确认从当前点能直接走到跳过后的下一个点。在线路最后一段，若跳过的恰好是全部剩余补捡点，就正常结束线路。绕障碍、上下台阶或维持角色状态所必需的指令和点位不应跳过。字段数值无效时按原路线执行；跳过数量超出范围或涉及传送点时，不跳过后续点，当前节点仍正常计数。

计数仅由配置组开关和有效的节点字段决定。未打开开关或没有有效字段的节点仍按原流程执行；联机同步和传送按原流程完成，计数不会替代同步。原本能跑这条线路的旧版和公版会忽略不支持的配置，继续执行原动作；旧版编辑器重新保存可能丢掉此字段。

调试时在 BGI 日志中搜索「拾取达标」，可看到 RGB 容错范围、标题原框和候选框的四连通块数、各行块数和累计。标题原框未命中时，备用框也只使用同一颜色范围；标题仍未确认的物品行不计入。
