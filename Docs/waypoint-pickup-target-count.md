# 线路节点按拾取数量结束动作

在执行线路所用的配置组中打开「拾够后提前结束节点动作」（默认关闭）。在单机线路的目标节点中保留原有的 `"action": "combat_script"` 和 `action_params`，再按需要填写同一个字段：

- `"pickup_target_count": 2`：拾够 2 件，结束当前动作，下一点照常走。
- `"pickup_target_count": "2/3"`：拾够 2 件，结束当前动作并跳过紧接的 3 个点位。斜线写法必须加双引号。

只有数字的字符串（如 `"3"`）也可以，效果与数字 `3` 一样，不跳点。

仅统计目标节点左侧「获得」列表的新增行，每行算一次。标题和每个物品行都在原始截图上使用两次取色之间的窄范围（R 236–242、G 229–235、B 216–222），去掉单像素后至少有 5 个四连通块才判有文字。标题用于确认列表，标题本身不计数。不读物品名、图标、行尾数量或拾取日志。移动中以角色的新定位计算距离，距离目标不超过 5 个线路距离单位即开始观察：还在走前一个普通点时也可以开始，同一份计数带到目标点。当前点本身也是拾取点时，优先观察当前点。观察开始时已有的行不计，旧行停留或滚动不重复计。列表确认消失后，本点累计保留，之后再出现的行继续累加。到点时不会停下来等列表画面稳定；观察已开启时会在动作期间继续计数。没有可信定位或可用画面时，原路线照常执行。

达标前照常执行原动作。达标时立即结束当前节点剩下的策略指令（包括可取消的等待），先释放该节点尚未松开的键，再继续执行路线。使用斜线写法时，跳过的点位既不移动过去，也不执行其动作；普通走路点也计入要跳过的点位数。没有拾够时，后续点位照常执行。已经发给游戏的操作无法撤回；松开长按的技能键也可能释放技能。

只跳过用于补捡的点位，确认从当前点能直接走到跳过后的下一个点。在线路最后一段，若跳过的恰好是全部剩余补捡点，就正常结束线路。绕障碍、上下台阶或维持角色状态所必需的指令和点位不应跳过。填写错误、跳过数量超出范围或涉及传送点时，保留原有流程。

配置组未打开、节点未填写有效值、联机场景或策略含不支持安全中断的指令时，仍按原脚本执行。原本能跑这条线路的旧版和公版会忽略不支持的配置，继续执行原动作；旧版编辑器重新保存可能丢掉此字段。

调试时在 BGI 日志中搜索「拾取达标」，可看到 RGB 容错范围、标题原框和候选框的四连通块数、各行块数和累计。标题原框未命中时，备用框也只使用同一颜色范围；标题仍未确认的物品行不计入。
