# BgiCoordinatorServer 协调服务

本服务为 BetterGI 茶包版及 Nexus BGI 联机助手提供房间协调、消息转发和网页控制入口。它是独立的 ASP.NET Core 项目，Docker 构建上下文为本目录。

## 源码与构建

- 茶包版源码：<https://github.com/kaedelcb/better-genshin-impact>
- BetterGI 上游：<https://github.com/babalae/better-genshin-impact>
- 服务端工程：`BgiCoordinatorServer.csproj`，目标框架 .NET 8。

使用 .NET 8 SDK，在本目录执行 `dotnet publish -c Release -o <独立输出目录>`。与服务端配套的网页资源和本目录许可文件会一起发布。本目录没有对仓库外共享源码的编译依赖。

Docker 构建仍在本目录执行。可通过 `--build-arg SOURCE_REVISION=<实际源码的完整提交号>` 标明镜像对应的源码提交；调用者须确保提交号与实际构建输入一致。若未提供提交号且构建环境无法取得 Git 信息，页面会如实显示“构建时未提供”，不会冒用仓库最新提交。

发布目录的 `wwwroot/legal` 包含 GPL 全文、项目说明、第三方声明及各许可证文本，Docker 最终镜像通过现有的发布目录复制步骤一并携带。`/legal.html` 为无需登录的公开声明页面，`/api/legal-info` 仅返回公开版本、源码地址及许可证文件清单，不返回运行配置或用户数据。
