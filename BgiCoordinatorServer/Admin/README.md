# 开发者联机锄地监控

1. 在服务端进程环境中设置 `ADMIN_MONITOR_PASSWORD`，长度至少 16 位。`docker compose` 会转发部署环境里的同名变量。通过服务器的密钥管理或私有环境配置注入，不要写进仓库或网页。
2. 用 HTTPS 打开 `/admin`。Production 环境拒绝 HTTP；仅 Development 环境允许本机 HTTP 预览。如果 HTTPS 在反向代理终止，设置 `ADMIN_MONITOR_TRUSTED_PROXY_IP` 为该代理连接应用时的**单个真实 IP**，并让代理覆盖 `X-Forwarded-Proto`。
3. 登录后每 10 秒刷新一次。页面只读，不发送游戏或控制房命令。未设置密码或密码不足 16 位时，管理入口返回 503。

“已开锄且有人在线”指服务端房间已收到开锄标记，并且至少一名成员有未超时、非断线宽限期的心跳。页面显示的是服务端当前内存中的房间；服务重启后不保留历史。开锄时长从首次开锄标记计算，线路是成员最近上报值，不等于已完成线路数。
