# 本版功能与开发验证范围

本版保留 C01/C02/C04–C11/C17/C20、公版共有能力及八类原生任务，配置组、JS、宏按资源引用混排。下表区分实现、组件检查与实际界面操作；游戏效果没有代测。

| 能力 | 正式入口和行为 | 本版验证依据 |
| --- | --- | --- |
| C01 多计划管理 | 选择／新建、管理中的删除与恢复；有运行责任时拒绝删除，原定义归档，保留资源和历史 | 实际新建、选择、保存、重启；WorkflowDeletionTests 验证归档、恢复、修订冲突和执行责任拒绝。删除确认没有用桌面自动化替用户执行 |
| C02 资源归属、顺序与混排 | 三步添加资源，真实时间轴排序、车道覆盖，真实资源编辑与更新引用修订；包含原生任务／整龙／组／JS／宏 | 实际七份旧配置资源、三步添加和定时卡片；ResourceCatalogServiceTests、FormalFlowContextTests、WorkflowPathTests 等相关回归 |
| C04 执行日期与参与状态 | 任务设置中的星期、是否在计划中执行；保留旧启用／过滤信息，明确选择才解除旧过滤 | WorkflowParticipationTests、旧配置兼容回归；实际原生旧配置列表及任务设置入口 |
| C05 连续执行与合法重复 | 顺序、路径和循环决定到达；每次到达保留节点／出现次数／轮次／尝试身份 | WorkflowRunnerTests、WorkflowPathTests；未把车道、列数或每天去重当作重复执行规则 |
| C06 从指定入口运行与恢复 | 节点运行入口、运行水位、暂停／恢复／跳过／重载；不确定事实保留责任，禁止自动重发 | 相关运行、水位与停止合同回归；隔离控制计划实际等待、暂停、恢复、停止和重启保留 |
| C07 定时与优先级 | 计划设置的普通／固定／灵活定时；节点时间和优先级 | 相关定时与运行回归；实际添加时间、拖动、直接 Ctrl+Z、保存和重启读回 |
| C08 循环和截止 | 每天定时或完成后循环，截止时间；等待不占执行端任务槽 | WorkflowRunnerTests、FormalPathWindowTests；计划设置接真实模型 |
| C09 跨天选择 | 计划设置中「错过本轮时间后等到次日」，保存到 skipAcrossDays | 定向设置回归与本轮实际保存、重启读回；设置面板不会被后台刷新切回任务表单 |
| C10 账号策略 | 任务设置中的绑定与切换参数，原账号掩码和旧顺序保留；识别和输入仍由 BGI 原子能力处理 | 兼容与参与策略相关检查；未操作真实账号或游戏登录 |
| C11 前置动作 | 任务设置中的兑换码等前置选择，保留旧配置含义和历史边界 | 兼容、策略与执行入口相关检查；未在游戏中兑换或操作月卡 |
| C17 完成后动作 | 计划设置中的完成动作，运行中抑制各配置重复尾部动作，保留终态作用责任 | 既有终态作用回归；未实际关闭游戏、软件或关机 |
| C20 执行与等待接续 | 同套 BGI 目录／进程／Windows 会话绑定，原身份准入；可靠空闲时重评等待并选择优先级最高者 | LocalWaitAutomaticContinuationTests、LocalWaitFinalizationContractTests 等；实际同套 IPC 资源读取。坏记录两条原停止失败仍保留 |
| 正式 WPF 编辑界面 | 精简顶部、可收起侧栏、集合展开／收回、分钟刻度、条件出口拖线、共享弹窗、互导 | 本轮相关 WPF 回归；实际主窗口添加、保存、拖动撤销、共享弹窗和重启。游戏资源安排后没有自动执行 |
| 旧数据打开即用 | 正常旧配置兼容读取；原生页面和助手资源目录自动显示；明确编辑才备份并写单份配置 | 七份真实旧配置的隔离副本实际读入，原件哈希复核不变；兼容与 UserRoot 回归。开发没有启动绑定真实 User 的最终入口 |
| 普通启动与恢复 | 双击启动槲寄生.cmd；同目录配对程序自动接续原 User 和原助手目录，本次启动等用户手动开始 | 同套目录定位检查、启动意图定向检查、实际隔离启动日志；保留旧自动设置，不在新入口自动运行旧启动流程或武装旧定时上线 |

已知未闭合项：corrupt／unsupported 准入记录下的两条原停止断言仍失败。当前实现拒绝不可确认的动作并保留原责任，不写假成功；恢复合法记录后可重试。正常有效记录的停止检查与实际控制计划停止成立。此项没有改绿或降级，原报告和等级保留。

第三方脚本、宏和外部线路仍依赖已安装的数据。缺失资源明确失败，不冒充完成。所有未观测的游戏、账号、终止动作效果按既定约定等待用户使用后主动反馈。
