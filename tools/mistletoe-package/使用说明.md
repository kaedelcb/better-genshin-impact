# 槲寄生任务中心使用说明

本目录中的 BetterGI 和 Tools/MultiplayerHoeingAssistant 是同套程序。使用原有 User 和助手数据，无需搬目录、准备迁移或设置环境变量。

1. 从旧助手的界面右上角「✕」或托盘正常退出助手，并正常退出正在使用同份 User 的旧 BetterGI。双击本目录的「启动槲寄生.cmd」。
2. 在助手中进入「槲寄生 → 任务中心」。选择已有计划，或从「管理 → 新建」开始；点击「添加任务」，依次选资源、填开始时间、确认添加，再点「保存」。这次启动等待你手动开始，保留原自动启动设置。
3. 点击任务卡片打开设置；拖动卡片按鼠标落点安排开始时间，默认吸附到五分钟，分钟视图或展开的集合支持一分钟。拖动后可用 Ctrl+Z 撤销，Ctrl+Y 重做。选「计划设置」修改名称、定时、循环、跨天、失败处理及完成后动作，修改后点「保存」。
4. 准备好后点「开始」。运行项显示当前可用的暂停、恢复、停止；「⋯」提供跳过、重载。保存不改变正在运行实例的设置，重载在节点边界生效。「视图」可打开共享独立窗口；「管理」保留导入导出、删除和恢复入口。

正常退出后再用同一入口打开，保存的计划和运行记录保留。停止或暂停的计划不会自动续跑；结果不明的记录保留待确认，请勿用重复开始替代恢复。

正常旧一条龙配置自动兼容读取，原文件不因打开而转换或覆盖。原生一条龙页面可选择原配置；原连续计划中被禁用或未绑定账号而过滤的项仍保留原状态，可在任务设置明确选择是否参与。真正编辑资源时先保存对应原字节到 User/OneDragon/.compat-backup；需还原时，先退出程序并另存当前修改，再只恢复对应的一份配置，不覆盖整个 User。

已知问题：运行准入记录损坏或版本不支持时，停止可能不可用，程序保留责任且不会显示已停止；修复有效记录后重试。相关两条原失败记录保留。外部线路、第三方脚本或宏仍依赖原数据中已安装的资源；缺少资源会明确失败。开发验证未操作游戏、账号、关闭游戏或关机，其效果沿既定约定由用户使用后主动反馈。

程序绑定的原数据目录见本目录 mistletoe-package.json；启动入口会检查同份数据的旧进程，提示正常退出，不替你关闭程序。
