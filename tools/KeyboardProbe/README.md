# BGI 偶发按键失灵诊断工具 v2.0

用于实体键盘的普通字母键失效、功能键仍正常、关闭 BGI 后恢复等难复现问题。Windows x64，使用系统 .NET Framework 4.x；独立运行，不需要替换 BGI。

## 使用

1. 故障出现时保留现场，解压并启动 `BgiKeyboardProbe.exe`。若 BGI 以管理员身份运行，诊断工具也右键以管理员身份运行。正常时也可选“正常状态基线”先采一轮。
2. **先不勾选模拟输入观察。**选“1. 故障现场”，鼠标点击“开始 30 秒”。前 20 秒在蓝色区分别按下并松开 **M、F、W、空格、Esc、F8 各 3 次**；不必长按，不要输入账号或聊天内容。
3. 最后 10 秒按提示放开全部按键；也可以提前点击“松手观察 10 秒”。此时不碰键盘，观察是否仍有输入。如果切回游戏，记住留出松手时间；**Esc / F8 仅在工具测试区测试**。测试区失焦时不增加窗口计数是正常的。
4. 每轮自动保存。工具选好下一标签后，**自行停止当前任务**再采第二轮，**自行退出 BGI**再采第三轮。阶段标签不等于已完成停止，工具不会替你操作 BGI。故障现场必须先保存。
5. 点击“导出对照包”，再点“打开目录”，把生成的 ZIP 与同期 BGI 日志一并提供。多轮结果保留在同一目录，不覆盖。可补充说明何时按键恢复、是否切过输入法或手动打开地图。

**可选的第二轮检查：**保存默认模式现场后，若故障仍在，可勾选“观察模拟输入标记”，手动选回对应阶段再采一轮。它会临时安装一个只读键盘钩子，观察系统标记为模拟的输入；可能改变钩子顺序/时序，所以默认关闭。每轮结束或关闭窗口都会卸载。出现模拟标记不代表发送者就是 BGI。

结果目录：`%LOCALAPPDATA%\BetterGI-KeyboardProbe\日期时间-进程号`。一键对照包只包含本次打开工具后保存的采集文件；不同次运行的目录需要分别提供。

## 数据及边界

- 仅在点击开始后的有限时段采集，默认共 30 秒；提前点击松手按钮则从点击时继续观察 10 秒。Raw Input 使用 INPUTSINK，无 NOLEGACY，不屏蔽原有输入；不注册热键、不发送模拟按键、不自动修复。
- 对 M/F/W/空格/Esc/F8 只保存累计按下/松开计数，其他键仅总数。每秒保存计数和前台进程、窗口句柄、布局。左右 Ctrl/Alt/Shift/Win 约每 50ms 采样，单独保存状态变化和观察到的持续区间；不保存文字、普通键的逐键序列、窗口标题、命令行、截图或转储。
- 修饰键初次采样就按住时，区间标为“采集开始前已按住”；结束仍按住则标为“结束仍按住”。记录的是观察区间，不是精确物理按住时间。实际采样次数和最大间隔也写入报告，忙碌时可能漏掉短暂变化。
- 松手阶段分别统计原始、测试窗口、可选模拟标记的计数。阶段只是操作提示，工具无法证明用户真的放开了手。不要把所有零计数直接认定为没有异常。
- 可选模式使用专用消息循环线程的低级键盘钩子，回调只累计计数并始终转交系统，不同步写盘或做业务。区分“带模拟标记”“未带模拟标记”“较低完整性模拟标记”；未带标记不能证明来自实体键盘，较低完整性是相对于观察者。没有发送者归属信息。记录安装/卸载状态及错误；Windows 可能静默移除超时钩子，因此安装成功和零计数也不证明它一直工作。
- 记录 BGI、助手及游戏的 PID、Session、程序路径、版本、完整性级别。路径可能包含用户名，外发前可检查。`0x2000` 通常为中完整性，`0x3000` 为高完整性；`unknown` 表示未读到，不能当作低权限。
- 进程列表受运行权限和会话环境影响；空列表不能证明 BGI 没有运行。应用清单声明 Windows 10/11 兼容，避免系统版本 API 返回旧兼容版本。
- “原始事件有、测试区没有”：先确认测试区获得焦点，并按秒级样本对照。可能涉及拦截、窗口消息或焦点问题，**不能据此直接认定是 BGI 的钩子**。
- “测试区正常、游戏不响应”：优先查游戏前台/输入模式、BGI 模拟输入、窗口/进程绑定，而不是把全部键盘失效当作既定事实。
- “原始事件也没有”：可能是采集注册、会话/桌面、设备或输入来源差异，不能直接判硬件坏。合成输入不保证产生 Raw Input。
- 修饰键状态来自诊断程序调用 GetAsyncKeyState，不能代替 BGI 线程状态；输入桌面不可访问时读数也有局限。两种模式都不能直接显示“哪个进程吞了按键”。
- 工具不自动作根因判定。BGI 内部钩子生命周期、回调耗时/返回值、SendInput 返回值仍需诊断版 BGI 才能取得；若对照锁定 BGI 输入链，再定向加这些记录。

## 构建与验证

`python -B tools/KeyboardProbe/build.py --output <新的输出目录>`

构建脚本使用仓库共享存储预约，直接调用系统 C# 编译器，再运行隔离自测并打包；不需要修改 PowerShell 执行策略。

`BgiKeyboardProbe.exe --self-test <结果 JSON 的绝对路径>` 运行隔离自测：修饰键变化/持续区间、模拟标记分类、F 键与原始包解析、截短包及非白名单保护、自己的窗口消息接收、Raw Input 和可选钩子的注册/卸载、实际 30 秒自动结束、松手阶段、连续采集、关闭中清理及对照 ZIP 导出。仅向自己的隐藏窗口投递消息；模拟标记使用合成测试数据，绝不调用 SendInput。输出明确标记 syntheticSelfTest，不能作为实体键盘输入、真实软件注入捕获或用户故障复现证据。

此工具是故障取证辅助，不是本次 BUG 的修复。新增工具不改产品工程、用户配置、日志或正在运行的 BGI。
