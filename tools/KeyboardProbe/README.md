# BGI 偶发按键失灵诊断工具

用于实体键盘的普通字母键失效、功能键仍正常、关闭 BGI 后恢复等难复现问题。Windows x64，使用系统 .NET Framework 4.x；独立运行，不需要替换 BGI。

## 使用

1. 正常时可先做一次“正常状态基线”。故障出现时保留现场，启动 `BgiKeyboardProbe.exe`；若 BGI 以管理员身份运行，诊断工具也右键以管理员身份运行。
2. 选“故障现场（BGI 仍运行）”，鼠标点击“开始 30 秒”。点击蓝色测试区，分别按下并松开 **M、W、空格、Esc、F8 各 3 次**。这里相当于检查普通窗口是否也收不到按键。不要长按；不要输入账号、密码或聊天内容。
3. 如需同时观察游戏，切回游戏只试 M、W、空格。**Esc / F8 只在工具测试区按**，避免触发游戏或 BGI 操作。工具窗口没有焦点时，测试区计数不增加是正常的。
4. 30 秒自动结束并保存，也可鼠标点击“结束并保存”。先保存故障现场，再在用户自行停止任务或退出 BGI 后选择对应阶段采集对照；工具不会替用户停止任务、退出 BGI 或释放按键。
5. 点击“打开结果目录”，将本次文件夹内的 JSON 和同时间段 BGI 日志一并提供。简要说明是否曾手动打开地图、切换输入法或按过修饰键。结果自动保存在 `%LOCALAPPDATA%\BetterGI-KeyboardProbe\日期时间-进程号`，每次采集单独一个文件。开始第二次采集不会覆盖第一次结果。

## 数据及边界

- 仅在点击开始后的 30 秒采集。Raw Input 使用 INPUTSINK，无 NOLEGACY，不屏蔽原有输入；不安装全局键盘钩子、不注册热键、不发送模拟按键、不自动修复。
- 对 M/W/空格/Esc/F8 只记录累计按下/松开计数；其他键只有总数。每秒保存一次计数和前台进程、窗口句柄、布局、修饰键状态，不保存逐键序列、文字、窗口标题、命令行、截图或转储。
- 记录 BGI、助手及游戏的 PID、Session、程序路径、版本、完整性级别。路径可能包含用户名，外发前可检查。`0x2000` 通常为中完整性，`0x3000` 为高完整性；`unknown` 表示未读到，不能当作低权限。
- 进程列表受运行权限和会话环境影响；空列表不能证明 BGI 没有运行。应用清单声明 Windows 10/11 兼容，避免系统版本 API 返回旧兼容版本。
- “原始事件有、测试区没有”：先确认测试区获得焦点，并按秒级样本对照。可能涉及拦截、窗口消息或焦点问题，**不能据此直接认定是 BGI 的钩子**。
- “测试区正常、游戏不响应”：优先查游戏前台/输入模式、BGI 模拟输入、窗口/进程绑定，而不是把全部键盘失效当作既定事实。
- “原始事件也没有”：可能是采集注册、会话/桌面、设备或输入来源差异，不能直接判硬件坏。合成输入不保证产生 Raw Input。
- 修饰键状态来自诊断程序调用 GetAsyncKeyState，每秒采样；短暂变化会漏过，不能代替 BGI 线程状态。采集窗口没有键盘钩子，所以也不能显示“哪个进程吞了按键”。
- 工具不自动作根因判定。BGI 内部钩子生命周期、回调耗时/返回值、SendInput 返回值仍需诊断版 BGI 才能取得；若对照锁定 BGI 输入链，再定向加这些记录。

当前排查优先级：BGI 输入监听/热键链与其他输入软件的交互；Ctrl/Alt/Shift 等残留状态或持续注入；游戏焦点/输入法/输入模式；启动切换时旧新进程、会话、权限、窗口绑定差异。优先级是调查顺序，不是根因概率。实体键盘信息使纯远控发键故障的优先级下降。

源码常规键盘监听没有发现对全部字母键设置 Handled/SuppressKeyPress 的路径，聊天热键保护只是跳过 BGI 自身动作。MouseKeyHook 5.7.1 的本机依赖反编译显示，未订阅 KeyPress/KeyDownTxt 时不走字符转换；当前订阅主要为 KeyDown/KeyUp，故不把输入法字符转换臆断为已知根因。钩子回调仍有同步业务，需现场证据判断。单纯钩子超时在现代 Windows 会导致钩子被移除，因此不能仅凭“卡住”解释长期选择性屏蔽所有普通键。

## 构建与验证

`python -B tools/KeyboardProbe/build.py --output <新的输出目录>`

构建脚本使用仓库共享存储预约，直接调用系统 C# 编译器，再运行隔离自测并打包；不需要修改 PowerShell 执行策略。

`BgiKeyboardProbe.exe --self-test <结果 JSON 的绝对路径>` 运行隔离自测：只向自己的隐藏窗口投递按键消息，检查原始包解析、上下键区分、截短包、非白名单键不记录、窗口消息接收、Raw Input 注册/注销和报告导出。输出明确标记 syntheticSelfTest，不作为实体键盘输入或游戏故障复现证据。

此工具是故障取证辅助，不是本次 BUG 的修复。新增工具不改产品工程、用户配置、日志或正在运行的 BGI。
