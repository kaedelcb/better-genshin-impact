# 原图素材

> 本目录内容为本地保留的原始素材，**不入库**（见根目录 `.gitignore`），仅以本文件作为占位保留目录说明。

本目录存放自动拾取（AutoPick）识别模板的**原始截图素材**，供 `Assets/莫版模板/generate_templates.py` 生成灰度模板使用。

## 图片作用

- 每张图片是从游戏截图中裁剪出的物品文字标识（如掉落物、矿石、植物、食材名称），尺寸规格为 **140×26**；
- 图片按物品来源分类存放：
  - `怪物掉落材料/`：各怪物掉落的材料（子目录按掉落怪物分组，如 A丘丘王、B深渊法师）；
  - `其余材料图-实用版 -新/`：其余可拾取材料（子目录按类型分组，如 A矿、B蒙德区域特产）。

## 重新生成流程

修改或新增素材后，运行：

1. `python Assets/莫版模板/generate_templates.py` —— 由原图生成灰度模板与 `templates.json`；
2. `python Assets/莫版模板/pack_to_bin.py` —— 打包为 `Assets/莫版模板.bin`（随程序发布）。

## 注意

- 识别运行时读取的是 `Assets/莫版模板.bin`，本目录图片不参与运行；
- 新增图片需符合 140×26 规格，否则会被 `generate_templates.py` 拒绝。
