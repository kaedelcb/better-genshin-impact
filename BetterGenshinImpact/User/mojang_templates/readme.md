# mojang_templates（额外莫版模板）

本文件夹用于放置自动拾取（莫版匹配）的**额外模板图片**，放入后重启程序即生效，无需重新打包 bin。

## 图片来源

1. **莫酱群获取**：群内分享的模板图片，保存到本文件夹即可。
2. **截图功能获取**：在「自动拾取」配置中开启「自动截图」，程序会自动保存识别为未知的拾取文字截图，将其中需要的图片放入本文件夹即可。

## 使用要求

- 图片格式：PNG，尺寸为 140×26 或 140×28（140×28 会自动裁掉上下各 1 行像素），宽度不超过 140；
- 文件名即交互名（建议使用中文物品名），放入后与内置模板同等参与识别；
- 与内置模板同名时，以本文件夹内的模板为准（用户模板优先）；
- 支持子目录嵌套，程序会递归扫描全部 PNG；
- 尺寸不符或无有效文字像素的图片会被自动忽略（详见程序日志）。

## 注意

- 新增或修改模板后需**重启程序**生效；
- 请控制模板数量，过多会降低识别速度；
- 本文件夹内 PNG 不入库，仅本 readme.md 随程序分发。

自动采集的未知物品截图保存在独立的 `User/mojang_template_captures` 目录。确认文件名和物品对应正确后，再放入本目录启用；未确认的截图不会自动加入拾取模板。
